# ⚡ Magnet-Harvester (磁力合并收割机)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

**Magnet-Harvester** 是一套为您量身打造的桌面磁力/ED2K下载链接**全自动汇总与洁癖归档工具**。它致力于消除手动整理下载链接的内耗，将散落在桌面的所有资源链结瞬间聚合，同时保证数据的绝对完整性与桌面的极度清爽。

## 💡 终极安全与核心特性

1. **绝对不过滤任何文本 (零缺失逻辑)**
   - 运行瞬间，自动扫描**【桌面现有的《汇总的所有磁力链接.txt》】**、**【桌面上的新 txt】**以及**【《已合并磁力归档》中的历史 txt】**。
   - 彻底解决由于新老文件合并导致的历史链接丢失问题。

2. **全局成提示保留标题**
   - 智能提取 `magnet:?xt=` 磁力链接及 `ed2k://` 电驴链接，并自动保留链接上方对应的**资源标题与描述**，避免下载时分不清资源。

3. **全局去重与重置**
   - 将所有来源的磁力链接在内存中进行**全局深度去重**。
   - 重新生成最新的《汇总的所有磁力链接.txt》。不管您运行多少次，以前存过的所有链接**绝对 100% 都在**，新增加的链接会自动融入进去！

4. **桌面洁癖级归档**
   - 提取完成后，原本散落在桌面的各种 txt 碎片会自动被打包并塞进【已合并磁力归档】文件夹。
   - 还你一个干干净净的桌面。

## 🚀 极简使用方法 (SOP)

不需要复杂的配置，只需一键：

1. 当你的桌面上散落了各种抓取下来的磁力链接 txt 文本时。
2. 双击项目中的 **`一键合并磁力链接.bat`**。
3. 等待一秒钟，所有链接已被抽干聚合到《汇总的所有磁力链接.txt》中，原文件已被收容。直接打开总文件复制到下载器即可。
